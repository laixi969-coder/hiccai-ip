# 05 · 执行流程与提问清单

## 一、开工前必须问的 7 个问题

不要一上来就看形象。先把这 7 个问题问完，判断才有依据。

| # | 问题 | 为什么要问 |
|---|---|---|
| 1 | 这个 IP 是**谁**要用？（品牌方/景区/城市/个人/平台） | 决定品牌型还是文化型 |
| 2 | 当前处于**哪个阶段**？（从 0 起盘 / 老形象升级 / 推新品 / 做副线） | 同一 IP 不同阶段第一用途会变 |
| 3 | **当下最先要解决的一个问题**是什么？ | 这就是第一用途的答案 |
| 4 | 它要出现在哪些**载体**上？（门头/包装/物料/小程序/表情包/潮玩/空间） | 决定识别结构要多"稳" |
| 5 | 有没有**已有资产**？（旧 logo、旧吉祥物、文化母体、故事、粉丝） | 文化型/内容型必须先盘资产 |
| 6 | **谁做决策、谁执行、预算是多少周期多长**？ | 决定是"能落地"还是"只能提案" |
| 7 | **不做什么**？（明确排除项） | 反面对齐比正面对齐更有效 |

> 第 3 题答不出来，说明项目本身还没想清楚 —— 这时应先把问题还给用户，而不是硬做方案。

## 二、五步执行流程

### Step 0 · 锚定当前阶段

把项目放进下面四种阶段之一（可多选，但要标主阶段）：

- **A 从 0 起盘**：没有任何 IP 资产
- **B 老形象升级**：有旧形象，但不适应当下载体/媒介
- **C 推新品/副线**：品牌 IP 已立住，要扩展产品线
- **D 单一场景突刺**：只要表情包/只要一次活动/只要文旅一个点位

阶段决定第一用途：
- A + 品牌需求 → 品牌型起步
- A + 潮玩/周边销售 → 产品型起步
- B → 先判断旧形象的识别结构出了什么问题，再决定是否重做
- C → 产品型，但必须先确认品牌型已经立住
- D → 社交型/文化型单点突破

### Step 1 · 判断第一用途

**动作**：
1. 用 `02-first-use.md` 的五型表，逐型问"是不是它"。
2. 选出**当下阶段的唯一主用途**（不要选两个）。
3. 写出判定依据：**"因为这个 IP 在当下阶段最先要解决的问题是 ______，所以它是 ___ 型。"**
4. 如果有次用途，写清楚它排第二的理由。

**判断口诀**：
- 要长期、要标准化、要进物料、要缩小成图标 → **品牌型**
- 要卖货、要有拥有欲、要有开箱冲动 → **产品型**
- 要用户主动转发、当嘴替 → **社交型**
- 有文化母体在前、要"看见就想起某地/某物" → **文化型**
- 有故事、有关系、要持续产出内容 → **内容型**

**反查**：把五型的"最容易犯的错"读一遍，看当前方案是不是正踩在某个坑上。踩坑往往说明类型判错了。

### Step 2 · 作用倒推形式

先列作用，再推形式。**顺序不能反。**

参考句式：
> 这个 IP 需要在【场景】里，让【谁】产生【什么作用】，因此形式需要【什么要求】。

例：
- 需要在门店门头和 24px 小程序图标里都能被认出 → 形式要求：外轮廓必须简洁可辨、核心符号必须能独立存在
- 需要用户第一眼就想拿起来 → 形式要求：材质要有手感暗示、体块要圆润可握、配色要有情绪温度
- 需要用户拿来当嘴替 → 形式要求：表情夸张可复用、留白够多、不依赖文字也能读懂

### Step 3 · 按三变量做结构（顺序不许跳级）

**优先级：轮廓 > 比例 > 五官位置大小 > 细节/装饰。上一级不过，不许动下一级。**

| 序 | 变量 | 要求 | 检验方法 |
|---|---|---|---|
| ① | **轮廓** | 有自己的形状，远看可辨；识别点合进主轮廓而非挂在外面 | 涂黑成剪影缩到 1cm，还认得出来吗 |
| ② | **比例** | 有"偏差"，不是平均脸；头身比/四肢/体块关系稳定 | 只改比例，性格出来了吗 |
| ③ | **五官位置大小** | 眼距/眼位/眼大小/嘴位/嘴宽 对应目标情绪 | 同一轮廓下能做出多种情绪吗 |
| ④ | 色彩关系 / 核心符号 / 细节 | 主辅色关系稳定；核心符号可独立存在 | 单拎出那个零件，能认出属于它吗 |

**禁止动作**：一上来加细节、靠换表情解决性格、靠服装配饰解决记忆点、表情没特点就整张重画。

**终检（结构 vs 装饰）**：拿掉服装、配饰、道具、妆容，只看素体 —— 还能认出来吗？还能看出性格吗？
**不能 → 你的"特点"是装饰不是结构，回到 ①/② 重做。**

→ 完整方法见 `03-three-variables.md`

### Step 4 · 验收

用 `06-checklist.md` 三张表逐条打分。**任一硬指标不通过 → 回到 Step 1 重判，不要只改细节。**

### Step 5 · 交付

按 SKILL.md 的「输出规范」六段式交付。

## 三、异常处理

| 情况 | 处理 |
|---|---|
| 用户不肯说商业目标，只想要"好看的形象" | 说明"不谈用途就只能谈装饰"，先给两套方案对比（品牌型 vs 社交型）让他选 |
| 用户要"既要品牌又要卖货还要表情包" | 指出这是三型混做，要排优先级；建议先做一个主用途立住，再跨类型 |
| 用户拿的是别人的爆款要抄 | 拆解它属于哪一型、它解决什么问题；抄形式不抄作用必死 |
| 项目是文化型但资料极少 | 先做文化资产盘点（什么最值得留下/最易识别/能当代化），资料不够就明确说"现有信息不足以做转译判断" |
| 用户是个人 IP 而非品牌 IP | 个人 IP 更接近内容型/社交型；第一用途通常是"承载内容"或"让粉丝表达认同" |

## 四、诊断（改稿）专用流程

用户拿已有 IP 来问"哪里有问题"时，用**逆推法**：

1. **先猜它想做成哪一型**（看它现在的载体和用法）
2. **再查它实际产生了什么作用**（用体检表）
3. **找错配**：想要的类型 vs 实际的设计侧重，错在哪
4. **给两条路**：路 A 保留现形象、补齐缺失的作用；路 B 重判类型、重做结构
5. **明确说清 A 和 B 各自的代价**，让用户选

> 最常见的错配：想做品牌型（要长期），却按社交型的设计逻辑做（追热点、造型复杂、靠情绪）；或想做产品型（要卖货），却做成了一个很稳的品牌吉祥物（没欲望、没系列感）。

**具体动手改稿时，切换到 `03-three-variables.md` 的 SOP**（剪影测试 → 比例对照 → 五官微调 → 素体测试 → 载体验证）。
**验收时叠加 `04-design-paths.md` 的五个"立得住"测试。**
