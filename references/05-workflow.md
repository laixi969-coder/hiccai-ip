# 05 · 执行流程与交付

以下为整理者的应用流程，可按任务缩短。先用用户已有资料填任务卡，再补问会改变方向的信息，不逐项审问。

## 任务卡

| 字段 | 记录内容 |
|---|---|
| 对象、受众、阶段 | 为谁使用，新建还是升级 |
| 第一用途 | 当下最先解决的问题；有次用途时排序 |
| 载体 | 尺寸、材质、使用环境与展示方式，未知项标待定 |
| 性格与反差 | 希望用户读出什么状态，哪些感觉要避免 |
| 已有资产 | 轮廓、配色、商标、文化母体、角色关系及不可改项 |
| 交付范围 | 文字诊断、设计方案、提示词或图像 |

信息不足且用户希望先推进时，声明暂定假设，给条件方案；涉及具体图像的结论要等实际查看后再判。

## 执行

1. 根据目标选第一用途，而非仅凭行业或题材判型。
2. 明确载体约束和需要保留的识别资产。
3. 从证据定位问题：目标错配、结构识别、性格表达、情绪、系列关系或产品适配。
4. 选择最小有效修改；整形任务通常先结构后五官，表情任务可直接调五官。
5. 把每个动作与作用、保留项、检验方式配对。
6. 按载体测试并记录状态；失败后返回对应问题层，不一律推翻定位。

## 动作表范例（整理者推演）

假设：品牌小熊要保留圆耳与蓝色，目标是踏实可靠，首先应用于包装。

| 证据/假设 | 作用 | 动作 | 保留 | 验证 |
|---|---|---|---|---|
| 用户描述体态偏轻，尚未见图 | 加强稳定感 | 尝试下移体块重心、缩短腿部，与现稿并排比较 | 圆耳、品牌蓝 | 看图后核实问题；目标用户比较气质 |
| 包装尺寸待定 | 小尺寸识别 | 减少不承载身份的碎纹理，集中面部焦点 | 核心符号 | 按实际包装尺寸输出样张，不虚报已通过 |

“下移”是待验证设计方向，不是通用于所有小熊的定律。

## 不同请求的完成条件

- 诊断：指出证据、关键问题、优先动作；缺图时给假设，不虚构观察。
- 改稿：交代改动、保留和预期作用；图像任务实际生成或明确工具限制。
- 系列：列角色分工、共同规则、差异规则，说明并排和单独如何验证。
- 文创：文化保留项、载体、互动/使用兴趣点、购买理由与打样问题。
- 品牌升级：已有认知资产、变化理由、应用样例和识别稳定性检查。
- 社交或内容型：见 [11 应用卡](11-application-cards.md) 的补充流程。
