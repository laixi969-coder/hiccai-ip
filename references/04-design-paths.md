## 一、他的分类总纲（阿乐体系第1集原文）

> 我的方法论**不是从画风出发**，而是从市场里的**识别、传播、实际应用和商业转化**出发。
> 不同项目，对应不同设计路径。

| 项目类型 | 设计路径（三个抓手） |
|---|---|
| **品牌型 IP** | **关联性** · **符号性** · **延伸性** |
| **产品型 IP** | **兴趣基因** · **产品适配** · **差异化** |
| **系列 IP** | **统一性** · **差异性** · **关系感** |
| **文创设计** | **文化母体** · **转化载体** · **购买理由** |

**解读 —— 每一类在解决不同的风险：**

### 品牌型 IP：关联性 / 符号性 / 延伸性
- **关联性**：形象和品牌之间有没有必然联系？换个品牌还能不能用？能 → 关联性不足
- **符号性**：能不能被压缩成一个符号/图标，缩小后依然可辨？
- **延伸性**：能不能标准化地铺到门头、包装、海报、物料、线上店铺、社媒？

### 产品型 IP：兴趣基因 / 产品适配 / 差异化
- **兴趣基因**：它凭什么让人产生兴趣？这个触发点是什么？（不是"可爱"，是具体的兴趣成因）
- **产品适配**：它能不能被做成实物？工艺、材质、成本、开模是否可行？
- **差异化**：在同类货架上，它和旁边那个有什么区别？

### 系列 IP：统一性 / 差异性 / 关系感
- **统一性**：放在一起，一眼看出是同一家族
- **差异性**：单独拿出来，每一个都能被记住、不混淆
- **关系感**：角色之间有没有关系（性格互补、身份分工、互动张力）

### 文创设计：文化母体 / 转化载体 / 购买理由
- **文化母体**：文化出处是什么？什么最值得留下？
- **转化载体**：转化成什么形态？（纪念品？日用品？空间？体验？）
- **购买理由**：用户为什么要买它，而不是买旁边的义乌小商品？

## 二、五个"立得住"测试（来自他的提问式标题）

这五个问题是他反复用来判"这个 IP 到底成不成立"的测试题。
**做任何 IP 方案，先用这五问自查。**

| # | 他的原题 | 在测什么 | 不通过的病灶 |
|---|---|---|---|
| 1 | 为什么很多吉祥物，**一放进包装就出问题**？ | **载体验证** | 形象只在平面稿里成立，进不了真实物料（比例失衡、细节糊、缩小即失识） |
| 2 | **画风很松弛，但这个 IP 还不算成立** | **风格 ≠ 成立** | 把"好看/有风格"当成了"成立"；画风是表现层，不解决识别与结构 |
| 3 | 为什么很多 IP **可爱，却不能作为吉祥物**？ | **可爱 ≠ 可用** | 只有情绪吸引力，没有结构识别力与延展能力 |
| 4 | 为什么很多 IP **看着可爱，还是记不住**？ | **可爱 ≠ 记忆** | 落入"平均可爱"，缺少偏差与核心符号 |
| 5 | 为什么 **5 个角色，最后看起来还是像同一个 IP**？ | **系列差异失效** | 只做了统一性，没做差异性；差异做在装饰上而非结构上 |

**一句话总结这五题**：
> 可爱不等于记得住，记得住不等于用得上，画风好不等于立得住，五个人不等于五个角色。

## 三、系列 IP 专题

**核心命题（他的原题）**：武当山文创 IP 系列化 —— **既要成套，也要各自有记忆点**。

这是系列 IP 的根本矛盾：**统一性和差异性同时要满足。**

### 三种系列做法（按他的口播还原，疗效递增）

**做法 A · 统一结构 + 配饰区分（他明确说的"常见"路径）**

> 「同一种动物做家族 IP 有两种典型的设计路径。**常见的是这种**：
> 先建立一个统一的结构，再通过配饰、局部细节做区分。
> 这种做法的好处是**统一性很强，一眼就知道它们是一套**。」
> —— 77 点赞标签

A 适合统一素体的换装系列；B 适合需要各角色独立识别的家族。口播承认 A 的统一性优势，不能把 B 写成唯一正确路径。

**做法 B · 结构级差异（他推荐的方法，77 点赞标签口播转述）**

> 「但我想讲的是另一种，角色之间**差异可以更大，又各自有特点**。
> 拿我这个案子举例，同样都是鹿，我**没有复制同一个结构**，
> 而是先从不同鹿的品种里去寻找它们**各自有辨识度的外形特征** —— 有的角大，有的脸长，有的轻巧。
> **第一步就先让它们在轮廓上长得不一样**；
> 然后再根据每个形态**赋予性格和角色分工**，继续调整它的**比例、五官和姿态** ——
> 憨厚的，设计得钝一点；机灵的，体态五官可以更舒展；主角呢，结构可以更稳重一点。
> **到这一步，每个角色就被结构彻底拉开了。**
> 再**加入服饰、配饰**这些元素去强化它的身份，**而不是靠配饰来做记忆点**。
> 最后统一画风，细化五官位置。
> 所以家族 IP 也可以看起来像一家人，但每个角色也都有自己的形态和记忆点。」

**→ 系列 IP 标准作业顺序（可直接执行）**

```
1. 找原型差异 → 从"同一品类的不同亚种"里提取天然不同的外形特征（角大/脸长/轻巧）
2. 轮廓先行   → 第一步就让它们在剪影上不同，不是先统一再分化
3. 赋性格分工 → 每个形态对应一个性格与角色定位
4. 比例五官   → 按各自性格分别调整比例、五官、姿态
5. 配饰强化   → 服饰配饰只用来"强化身份"，不承担记忆点
6. 统一画风   → 最后一步才收敛画风，保证"看起来像一家人"
```

**核心结论**：
> **统一性放在最后做（统一画风），差异性放在最前做（先拉结构）。
> 需要独立角色时可采用这个顺序；共用素体的换装系列不因此判为失败。**

**做法 C · 把属性"长进"结构（武当山，36 点赞标签口播转述）**

> 「上一条讲了武当山文创做毛绒，材质变了，设计路径就会变，鬼将从武将转化成了陪伴型的守护角色。
> 那基调定下来了，后面要解决的是**怎么把四个不同的角色做成一套系列**。
> 这里我重点讲两个角色，金童和桃花女。
> 如果按照常规的结构去做，很容易变成常见的古装娃娃。
> 所以我的判断是 —— **不要把属性当做装饰贴上去，而是让属性长进角色结构里**。
> 金童代表福运和聚宝，所以我把**元宝符号放大，变成了它的记忆点**；
> 桃花女也是一样，**把桃花变成角色本体**。
> 这样四个角色的组合，**每个角色都有自己的第一识别点**。
> 还有一个很重要的点：**IP 做产品，要注重它怎么被展示，怎么去售卖**。
> 所以后面我又做了**终端展示柜**，让这套 IP 进入一个完整的武当山毛绒展示场景，让主题氛围产生代入感。
> **系列 IP 放在一起，画风要像一个世界里的；拆开，各自又成立，保证最后能落地销售。**」

**→ 系列 IP 的两条硬指标 + 一条常被忽略的第三条**

| 指标 | 判据（依据转写整理） |
|---|---|
| **合起来** | 「放在一起，画风要像一个世界里的」 |
| **拆开来** | 「拆开各自又成立」 |
| **卖得掉** | 「保证最后能落地销售」+ 做**终端展示柜**（陈列场景也是设计的一部分） |

> ⚠️ **第三条最容易被漏**：系列 IP 不只是"图形统一 / 各自可辨"，
> 还要**为它的售卖场景做设计**（展示柜、陈列氛围、主题代入感）。
> 直接对应开头的"从市场的识别、传播、应用和商业转化出发"。

**系列 IP 自查表（更新版）**

| 检查项 | 做法 |
|---|---|
| 统一性 | 把 5 个角色并排缩到很小，还看得出是同一家族吗？（共用轮廓语言/比例家族/色彩关系） |
| 差异性 | **只看剪影**，能把 5 个角色一一指认出来吗？ |
| 关系感 | 角色之间有没有可讲的关系（性格互补/身份分工）？还是同一个模子的 5 个变体？ |
| 反装饰测试 | 把服装配饰全拿掉，还是 5 个不同的角色吗？ |
| **属性内化测试** | 每个角色的核心属性，是"贴在身上的装饰"还是"长进结构里的本体"？ |
| **售卖场景测试** | 有没有为它设计陈列/展示场景？放进货架或展示柜，主题氛围成立吗？ |

### 老虎家族：5 个角色怎么在结构上拉开（685 点赞标签口播）

> 「帮 AI 改稿，这是 AI 生成的老虎家族，但**看着像一个角色，性格区分不够鲜明**。
> **头身揉成一个大体块，四肢加粗，做成 T 型** → 更厚重、更勇猛，自带压迫感；
> **头收窄、拉长，整体做成长方形，五官收紧** → 更克制、冷静；
> **身体和四肢往里收，揉成一个团** → 更软、更娇羞，像默默打辅助的；
> **毛发炸开，结构推成三角形，嘴张大** → 一看就是情绪波动最大的；
> **头放大，脸横向拉宽，五官放松，整体做成圆角方形** → 有种"怎么都行"的松弛感。
> 这样五个角色的差异，**就不是靠配饰区分，而是用结构拉开性格**，
> 长相自然就有了差别，每个角色也会长出自己的特征。」

**→ 可复用句式**：`体块形状（T型/长方形/团/三角形/圆角方形） → 性格（厚重/克制/软/外放/松弛）`
**5 个角色 = 5 种基础几何体块。** 这是"结构级差异"最好抄的一种实现方式。

## 四、文创设计专题

来自「案例拆解」9 集中的 5 集，加上口播到位后的 5 个完整实操案例。

### 他的判词（原题 + 口播转述相互印证）

| 原题 | 口播转述支撑 |
|---|---|
| 文创做出来没意思？**别只把原型复刻过来** | 「把文物直接缩小，把图案简单卡通话，应用在一个普通的载体里 …… 往往会做出来一个很普通的**纪念品**，不能做成当下可持续使用的产品」 |
| 地标做成卡通不难，**难的是做出购买理由** | 「很多城市 IP、做文创都会先把地标卡通化。**看着不难看，但就是卖不动** …… 很多文创最后稀缺的**不是文化，而是购买理由**」 |
| **让文化不只被观看，也被使用** | 「让国宝不只是被观看，也可以被使用」「设计的意义不是把传统元素贴到产品上，而是找到一种融入今天生活的方式」 |
| 武当山文创IP升级：**为什么做毛绒必须改原型**？ | 「PVC 软胶可以靠开模做出角色的层次，但**毛绒材质更主要的是靠布料拼接，再用棉花撑出的体积**。这也是很多 IP 做毛绒产品**一打样就变形**的原因」 |

### 五个完整实操案例（口播转述，可直接作范例讲解）

#### 案例 A · 辽三彩鸳鸯杯（513 点赞标签）—— 载体转化

> 「这是辽博的辽三彩鸳鸯杯。如果照着原型直接做摆件，当然能做，**但对今天的用户来讲，只能摆着，它用不上**。
> 所以这类文创，我会**先判断两件事**：
> **第一，它的原型最该保留下来的是什么？**
> **第二，它更适合进入今天什么样的一个产品载体？**
> 这个作品我最想保留的是**它的吉祥的寓意**，还有**原型最核心的识别关系**。
> 但这个"杯"的载体放到今天它并不常用，所以我把它**转化成了一个日常可以使用的咖啡杯** ——
> **鸳鸯的吉祥寓意保留，非遗工艺保留，再加上一个转化兴趣点**：
> 比如把这个嘴部变成了**可以插吸管的结构**，那这样平时又能倒水，又能插着吸管喝。
> 我理解的文创，**不是把文化直接贴上去，也不是把原型直接复刻出来**，
> 而是**先判断它应该保留什么，再去判断今天它能变成什么**。
> **文创设计最重要的往往不是画面，而是载体的转化判断。**」

**→ 可提取的公式**：`保留什么（寓意 + 核心识别关系） + 进入什么载体（日常可用） + 转化兴趣点（插吸管的嘴）= 新文创`

#### 案例 B · 唐风旋转桌宠（82 点赞标签）—— 转化"状态"而非"形象"

> 「我抽到的文物是《虢国夫人游春图》。看到这幅画卷以后，我先做了一个判断：
> **觉得这个文创不应该只是提取人物形象，而是应该转化画面里"出游的状态"**。
> 那接下来我重点思考两个问题：
> **第一，这种出游状态适合变成什么样的产品形式？**
> **第二，用户为什么愿意买回去用起来？**
> 这幅画最吸引我的是**出游感和人物关系**，因为它不只是一个单独的人物，
> 而是一组人在春天出游的这种状态。所以我希望这个文创也能保留这种**轻松流动的感觉**。
> 最后我把它设计成了一个**可以旋转的桌面摆件**：
> 底座是一匹小马形成旋转结构，人物和小马之间用**磁吸连接**，可以骑在马上，也可以拆下来单独摆放。
> 这幅画还有一个很容易被讨论的点，**就是谁才是虢国夫人**。
> 我把这种**人物辨认和猜测转化成了"收集机制"** —— 不同人物通过发型、服饰和配饰进行区分。
> 用户在辨认、收集、组合的过程，其实是再次进入这幅画的思考。
> 所以我的设计想法是：**把《虢国夫人游春图》的观看体验转化成了一个可以互动的桌面文创**。
> 文创设计不只是换了一种画风，**更重要的是判断它怎么进入当代人的生活**。」

**→ 三个可复用的转化层次**
1. **形象层 → 状态层**：不提取人物，提取"出游的状态"（更高维的母体）
2. **观看 → 互动**：旋转结构 + 磁吸拆分 + 收集机制，让人"玩进去"
3. **争议点 → 参与机制**：画里最有话题的疑问（谁才是虢国夫人），直接做成产品玩法

#### 案例 C · 沈阳地标像素风（65 点赞标签）—— 风格决定玩法

> 「很多城市 IP、做文创都会先把地标卡通化。看着不难看，但就是卖不动。
> 不是卡通化不对，**是太普通的卡通化，就容易同质化**。
> 因为**风格会决定后面产品载体和玩法**。
> 这是沈阳的城市地标，**把它变成像素风之后，它就不只是一个平面的城市形象**：
> 可以先做成这种潮流版画；再往下，还可以做成 **DIY 拼装摆件**，让用户自己去动手拼进去；
> 再往后，还可以做成一整套**可以收集的城市地标文创**。
> 那这个时候你会发现 —— **是风格决定了后面产品的玩法**。
> 所以文创设计，先想的不是让它怎么变得好看，**而是先判断它能不能让人愿意带走**。
> 因为很多文创，它最后稀缺的不是文化，**而是购买理由**。」

**→ 关键洞见**：**风格不是审美选择，是商业选择** —— 像素风比写实卡通多出"拼装 / 收集 / 版画"三种玩法。
选风格时问：**这个风格能解锁哪些产品玩法？**

#### 案例 D · 新华书店白头叶猴（45 点赞标签）—— 一个 IP 延伸成一个文创系列

> 「这是广西崇左的特色动物。我们抓取一下特征做成新华书店的吉祥物：
> 头部留了一个莫西干的发型，处理成图形化；再把白毛区域拆分成**头部和前胸两个体块**；
> 身体压得壮实一点，让它看起来更踏实、更稳一点。加上细节，上色。
> **基础形象出来之后还没完，接着做书店文创。**
> 但这里要注意一下：现在用 AI 做周边，会做成"一个 IP 不停地贴到不同的产品上"，
> **但这种产品落地本身是没有兴趣点的。**
> **IP 延伸成文创，一定要根据载体重新设计**：
> 比如**书签可以利用猴子的尾巴**；**手帐本可以让猴子翻书**，也可以"齐天大圣"；
> **冰箱贴可以做成半立体，头探出来**。
> 另外像这种载体，本身的颜色不够，就要通过**辅助图形、排版补充色彩**。
> **IP 延伸不是复制，而是每换一个产品都要去重新思考，怎么让它更有吸引力。**」

**→ 一条铁律**
> **「IP 延伸成文创，一定要根据载体重新设计」** —— 一个形象贴到 N 个产品上 = 没有兴趣点。
> 每换一个载体，都要重新问"这个载体能玩出什么"（书签用尾巴、手帐翻书、冰箱贴半立体）。

#### 案例 E · 书法帖 → 露营杯（20 点赞标签）—— 从"人生态度"而非"形式"提取

> 「《仲尼梦奠帖》是欧阳询唯一传世的真迹。它要被设计成什么样的文创产品，才能进入今天的生活？
> …… 书法做文创，难的**不是能不能做，而是怎么跳脱常规形式做出新意**。
> 复刻图案容易变成纪念品，太复杂又容易丢掉书法本身的奇趣。
> 另一个难点是，这幅帖写的是欧阳询晚年关于生死的人生感受，**题材有些重**，所以**不能把它做得太热闹**。
> 后来我们反复讨论、筛掉了很多方案，最后留下来的是一套**露营杯**。
> 很多人可能觉得奇怪，书法和露营杯有什么关系？
> **因为我们发现书法不只有形式，还有它想表达的人生态度** ——
> 露营是一种**慢下来、回到生活里的状态**，这和这幅帖给我们的感受其实很接近。
> 于是我们从帖里提取了"如影随形"四个字，向上延伸出**杯身的结构**，
> **四种配色对应人生不同的滋味**。杯底还藏了一个小设计，带水轻轻一按，就能复刻帖中的字。
> **让国宝不只是被观看，也可以被使用。**
> 我更加确定：**设计的意义不是把传统元素贴到产品上，而是找到一种融入今天生活的方式。**」

**→ 最反直觉也最有效的一招**：**当形式对不上时，去找内容里的"态度 / 状态"，而不是硬找形式关联。**
书法 × 露营杯 = 都在讲"慢下来"。

### 文创设计的三问（对齐"文化母体 / 转化载体 / 购买理由"）

1. **文化母体**：这个文化里，什么最值得被留下？什么最容易识别？什么能被当代人理解？
   → 513 点赞标签的口播版本更锋利：**「它最该保留的是什么？」**（是寓意？是识别关系？是态度？）
2. **转化载体**：它要变成什么？（毛绒 / 桌面摆件 / 咖啡杯 / 露营杯 / 拼装玩具 / 空间 / 体验）
   → **不同载体要求不同原型**（109 点赞标签：毛绒靠布料拼接与填充，PVC 靠开模；做毛绒需检查原型适配）
3. **购买理由**：一句话说清"为什么买它"。说不清 → 转译还不到位
   → 65 点赞标签：**「很多文创最后稀缺的不是文化，而是购买理由。」**

> 呼应 02 的文化型判断："如果一个文化型 IP，必须靠长篇讲解，用户才知道为什么要买，说明它的视觉转译还不够直接。"

### 文创项目的额外两条（口播里反复出现）

4. **转化兴趣点**：保留文化的同时，**必须人为加一个"想用 / 想玩"的钩子**
   （513 点赞标签"嘴部变成插吸管的结构"；82 点赞标签"磁吸 + 旋转 + 收集"；65 点赞标签"DIY 拼装"）
5. **载体约束提前**（109 点赞标签）：**材质变了，设计路径就要变**
   > 「做产品，**材质不同，设计路径就不同**。」
   > 毛绒改原型、软胶可开模、平面可印刷 —— **不是先设计完再找工艺，而是工艺决定造型**。

### 商业周边的一条判断（119 点赞标签）

> 「很多传统企业做 IP 周边，通常会想到挂件、摆件或者门头装置，但**这些形式的周边每个品牌都做得差不多**。
> 真正符合品牌的周边**应该和品牌本身有关系**。比如这个品牌，可以先判断做成**和家电有关的周边载体** ——
> 比如迷你屋或者微景观玩具，把冰箱、洗衣机、厨房、客厅这些场景放进去，也可以做成**自由的组装形式**。
> **周边形态先定下来，再反推 IP 怎么调整** —— 比例松弛一点，表情别太僵，品牌色保留下来，
> 让角色和场景放在一起更融洽。
> 那这样做出来的，就不是谁都能套的**模板化周边**，而是品牌独有的**场景化文创**。
> 所以有时候**周边不是为了有而做，IP 也不是为了变而改**，
> 可以先判断它要进入什么样的产品载体，再决定 IP 该变成什么样。」

**→ 反直觉顺序**：**先定周边形态，再反推 IP 怎么改**（不是先有 IP 再想周边）。
这也是 02「第一用途」在产品型上的具体展开。

## 五、品牌型 IP 专题

「案例拆解」第5集：**品牌型IP，我是这样思考和设计的。**
以及 1852 点赞标签对 TRON（波牛）升级的完整点评推演。

### 三性检查（关联性 / 符号性 / 延伸性）

| 性 | 自查问题 |
|---|---|
| **关联性** | 这个形象和品牌之间是什么关系？把 logo 遮住，还看得出属于哪个品牌/品类吗？ |
| **符号性** | 能不能提炼出一个可独立存在的符号？缩到 24px / 做成图标，还认得出吗？ |
| **延伸性** | 门头 / 包装 / 海报 / 物料 / 小程序 / 线上店铺 / 社媒，铺一圈会不会崩？ |

### 先学怎么"读"一个品牌 IP 升级案（1852 点赞标签口播转述）

> 「TRON 升级了自己的品牌吉祥物波牛。一眼看到会觉得只是眼睛变大了、多了嘴巴和虎牙。
> 但站在品牌 IP 设计的角度，这次升级真正想调整的，我理解是**开始尝试让这个角色承担更多的传播作用**。
> **新版开始加入了情绪** —— 以前更像一个品牌图形，现在更像一个**人格化的角色**，
> 完善了可情绪化的设定，后续可以承载品牌更多的内容表达。
> 品牌手写字母 T 被融入了角色，**这是品牌型 IP 很重要的一件事，就是建立品牌关联**。
> 不同品牌建立的关联方式也不一样，**可以来自产品，可以来自理念，也可以来自品牌名**。
> 这次选择的是品牌手写字母 T，也是一个合理的方向。
> 我觉得这次 IP **真正升级的不是造型，而是传播能力**。
> 从宣传片里也能看到，新版比旧版更适合做动画表情和内容传播，
> 品牌发生的重要事件也可以继续做成不同的 IP 形态。」

**→ 读一个品牌 IP 时该问什么（他示范的四个问题）**
1. 这次改动**真正想调整的是什么**？（表面是造型，实质是传播能力）
2. 角色**有没有情绪能力**？（品牌图形 ↔ 人格化角色）
3. **品牌关联建在哪**？（产品 / 理念 / 品牌名 —— 三选一）
4. **能不能承载后续内容**？（做动画、做表情、做事件传播）

### 再看他自己怎么做 · 品牌型 IP 三判断（79 点赞标签口播转述）

> 「那如果继续沿着这个方向设计，我会**先做三个判断**：
>
> **身份** —— 品牌叫波牛，可以让角色更像牛；同时它又是一家金融品牌，
> 我希望它给人的感觉是**踏实、可靠、沉稳**，从**轮廓上**给出一种值得信任的感觉。
>
> **符号** —— 官方已经把 T 放进了角色里，那如果是我，**更倾向于把 T 长进角色本身**：
> 比如牛角和脸形成了一个 T，头脸也可以是个 T，**让品牌符号成为角色的必要部分**。
>
> **延展** —— 品牌型 IP 做延展的时候，我会**先考虑到应用场景和作用**。
> 这个品牌我觉得最适合数字产品，所以**品牌发生的重要事件都可以变成新的 IP 形态**：
> 比如"豪餐牛"，记录老板花 450 万美元和巴菲特吃饭；
> "香蕉牛"，记录老板 4500 万美元拍下并当场吃掉的艺术香蕉；
> "太空牛"，记录老板花了两个亿去太空玩一圈。
> **每一次的品牌事件都能变成一次新的 IP 传播。**
>
> 所以品牌型 IP 要真正设计的，**不是一个吉祥物，而是一套能够不断生长的品牌资产**。」

**→ 提炼成可执行的三问三答**

| 判断 | 问什么 | 判断标准 |
|---|---|---|
| **身份** | 角色要代表什么品类 / 气质？ | 气质要能**翻译成轮廓语言**（"踏实可靠"→ 轮廓上给出信任感） |
| **符号** | 品牌资产怎么进角色？ | **"长进" > "贴上去"** —— 品牌符号应成为角色的**必要部分**（拿掉它角色就不成立） |
| **延展** | 品牌往后会有什么事？ | **先定场景与作用，再定形态**；把未来的品牌事件预埋成 IP 形态 |

**金句（引用前须回查转写）**
> **「品牌型 IP 要真正设计的，不是一个吉祥物，而是一套能够不断生长的品牌资产。」**

### 品牌吉祥物的改稿标准路径（667 点赞标签口播）

> 「帮客户改个稿，这个看着像是 AI 生成的，能看，但是**不能作为品牌的吉祥物**。
> 原因就是**太像海报素材了，看起来不是一个容易被记住的角色**。
> 怎么改呢？**从源头出发**。给到的品牌性格是"踏实、可靠"。
> 我们可以用**几何图形来锁定结构** —— 上面稳一点，下面沉一点，看着就踏实了。
> **有了结构的约束，再去放轮廓和五官**，形象性格自然就出来了。
> 最后给它一个**稳定的识别点**，比如这个红鼻子 ——
> 这样**无论后面怎么延伸，特征都会被保留下来**。
> 那做这种品牌吉祥物的路径呢，可以**先明确性格，再锁结构，再打上符号**。」

**→ 品牌吉祥物四步路径（他明说）**
```
明确性格 → 用几何图形锁结构 → 释放轮廓与五官 → 打上一个稳定识别点
```
**关键**：识别点要能**在后续所有延展中被保留** —— 这是"符号性"的落地检验。

### 品牌型 IP 的反面判据（1819 点赞标签口播）

> 「这个是 AI 生的狐狸，很可爱，大眼睛、大耳朵、低眼看，没什么问题，**但出圈难，因为它太安全了**。
> AI 很容易生成一个**大众都喜欢的平均值**，但很难让人记住。
> 如果把它往品牌 IP 方向改：
> **第一，先做一个能被记住的轮廓** —— 所以我会先把头和耳朵处理成一个更明显的 **V 字形轮廓**，
> 这样头部就不再是普通狐狸的轮廓，而是开始有了自己的**形状记忆**；
> 再把身体拉高，四肢变细，开始有一点苗条、冷感、小脾气的气质，
> 表情让它有一点疏离感、独立女性的感觉，然后再处理毛色细节、配饰元素，
> **不抢主体的同时，增加角色的形象锚点**。
> 这样调整之后，就有了性格和记忆点。
> **AI 可以生成一个好看的形象，但 IP 需要的是被记住。**」

**反面题**（阿乐改稿第2集）：**为什么很多吉祥物，一放进包装就出问题？**
→ 因为设计时**只在平面稿里成立**，没做载体验证。
包装是缩小的、有折面的、有印刷限制的、和信息层级共存的。**载体验证是品牌型 IP 的必过关。**

## 六、五型（02）与四路径（本篇）的关系

两套分类不冲突，是**不同层级**：

| | 分类依据 | 回答的问题 | 用法 |
|---|---|---|---|
| **五型**（见 02） | 第一用途 | 为什么要做这个 IP？它最先要解决什么 | **判断阶段**用 |
| **四路径**（本篇） | 项目落地类型 | 这个项目该怎么设计 | **执行阶段**用 |

**对应关系**：

- 品牌型 IP：两处一致
- 产品型 IP：两处一致
- **系列 IP**：横切概念 —— 品牌型可以做系列，产品型也可以做系列；判型仍按五型，做系列时额外叠加"统一性/差异性/关系感"
- **文创设计**：文化题材的落地路径；主用途可能是文化转译，也可能是商品购买，按当前目标判断，再用"文化母体/转化载体/购买理由"执行
- 社交型 / 内容型：五型有，四路径未单列（他的公开内容里这两类着墨较少）

**推荐的组合用法**：
```
用五型判断第一用途  →  用四路径确定执行抓手  →  用三变量（03）做具体改稿
```
