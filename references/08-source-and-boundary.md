## 三、使用边界

1. **本 skill 已包含该账号的全部可获取内容** —— 58 条作品清单 + 4 合集 55 集标题 + **54 条视频口播逐字转写**。
   仍未掌握的是**改稿前后的图像对比**（口播描述得出、图片看不到）。
2. **口播为语音转写，可能有同音字误差** —— 语义准确，但**逐字引用专名时请核对**。
   已知易错项：**徐阿乐 → 薛阿乐**（他自称时最常被误识）、鬼将 / 龟匠、虢国夫人 / 国国夫人、
   Labubu / 拉布布、轮廓 / 容阔、憨厚 / 寒厚、萌 / 猛、局气 / 居气、出图快 / 出图块。
   完整清单与说明见 `10-spoken-corpus.md` 开头。
3. **方法论推演 vs 当事人原意** —— 本 skill 中用他方法论"推演"新项目（如给用户的 IP 提建议）时，
   属方法论应用，不代表徐阿乐本人观点。但**引用他视频里的原话时，已是真实原话**。
4. **商业授权** —— 原始表达版权归原作者。内部学习、方案推演、方法论应用没问题；
   **对外出版、培训售卖、直接署名发表前应先取得授权**。
5. **抓取行为说明** —— 本次抓取使用**用户本人已登录的浏览器会话**（用户主动授权），
   **未绕过任何验证码**、未编写任何验证码破解逻辑。不包含任何账号凭证的存储。
