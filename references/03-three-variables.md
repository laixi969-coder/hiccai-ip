## 〇、他的两句招牌对句（口播原文，反复出现）

> **「表情决定情绪，轮廓决定气质。」**
> —— 1.6万赞《同一只狮子》、1064、4177、1229、715、6709 等十余条口播中重复出现

> **「轮廓决定识别，元素决定关联，结构决定延展。」**
> —— 368 集《一点小改动，让角色更生动》结尾总结

这两句就是三变量体系的**压缩版本**：轮廓管识别与气质，五官管情绪，元素（装饰）只管关联主题，
而**结构负责能不能延展成产品**。四条各司其职，不可互相顶替。

## 一、为什么是这三个变量

一个 IP 形象为什么"没记忆点""没性格""情绪不足"，绝大多数人第一反应是**加细节**。
他的判断正好相反：

> **别加细节，先改轮廓。**
> **IP细节越多，记忆越分散，轮廓才是第一识别。**
> **IP的记忆点，不是装饰出来的。**

因为 IP 的识别与性格，**不来自细节，来自三个结构性变量**：

| 优先级 | 变量 | 决定什么 | 他的原话（口播转写） |
|---|---|---|---|
| ① 最高 | **轮廓** | 第一识别 + 气质 | 「轮廓明确，识别集中，容易被记住」「轮廓本身就有了性格和识别」 |
| ② 次之 | **比例** | 气质 / 性格 | 「比例不拉开，永远安全，安全就等于普通」「不是细节不够，是比例这一步没把感觉立住」 |
| ③ 再次 | **五官位置大小** | 情绪 / 表情 | 「不是画的不够多，是五官关系还没被拉开」「先用五官之间的关系，把情绪拉开」 |
| ④ 最低 | 细节 / 装饰 | 强化主题（**不能替代结构**） | 「IP 不能靠换服饰、靠表情来制造特征」「服饰和配饰不能代替角色本身的特点」 |

**顺序不能反。** 轮廓不对，调五官白费；比例不对，加细节白费。

> 但表中每一条措辞都**已由口播原文逐字验证**，不再是标题推测。
> 另有他本人的压缩版对句可直接引用：「**表情决定情绪，轮廓决定气质。**」

## 二、变量一 · 轮廓（第一识别 + 气质）

**判断标准**：把形象涂成纯黑剪影、缩小到 1cm，还能认出来吗？

**他的核心论述**：
- 轮廓才是第一识别
- IP 细节越多，记忆越分散 —— 细节在争夺注意力，反而稀释了识别点
- 为什么 IP 轮廓改圆之后，反而更有记忆点？→ **圆是高识别度的形态**：圆更整体、更少干扰、更统一，远看更稳
- 为什么有些 IP，只看轮廓就能看出性格？→ 因为性格被编码进了外轮廓的形状语言

**口播原文还原（519 集《为什么IP轮廓改圆之后，反而更有记忆点》）**：

> 「这个是 AI 生的小龙，看着可爱，但有点普通，因为**五官体型太标准了**。
> 那如果**把头和身体揉成一个团**，角色马上会变得更软、更憨，有想让人抱一下的感觉；
> 再把嘴巴拉大，眼睛简化，结构也简化，情绪会更明显，
> 这样**视觉重心就不会太散，焦点在面部，重心在肚子上**。
> 这样它就不是靠细节推出来的普通小龙，而是靠简化的结构就加强了性格的体现。
> **用五官赋予情绪，用轮廓强化性格。**」

→ 这段把「轮廓为什么能定性格」讲透了：**轮廓的本质工作是"收拢视觉重心"**。
轮廓越整体，注意力越集中，性格越容易被读出来；轮廓越碎，注意力越分散，就越平庸。

**口播原文还原（506 集《IP细节越多，记忆越分散，轮廓才是第一识别》）**：

> 「这个是 AI 生的狗，态度是有的，靠眼神、动作、配饰去体现的，但**缺少识别性**。
> 那如果先把头和身体**揉成一个整体，外轮廓改成三角形**，重心下压，角色会变得更敦实，
> 有那种拽拽的、牙长的感觉。还可以**把头发盖住眼睛，耳朵一上一下，弱化原来对眼神的依赖**。
> 不用靠瞪人，也能体现酷酷的态度。手脚保留动作，让**视觉中心始终落在三角形体块上**。
> 这样它就不是靠繁琐细节堆出来的态度，而是**轮廓本身就有了性格和识别**。
> **IP 细节越多，记忆越分散；轮廓明确，识别集中，容易被记住。**」

**口播原文还原（386 集《IP的记忆点，不是装饰出来的》）**：

> 「帮 AI 改稿，这是 AI 生的蝙蝠，一眼看着挺凶，耳朵、翅膀、眼睛都是常见的处理方式。
> 那如果**把嘴拉到很大**，用一圈尖牙吓唬人，再把猪鼻子特征放大，身体缩小，
> 翅膀和手脚全部弱化，**让嘴成为绝对的视觉重心**。
> 用红色的眼睛、粉色的鼻子和白色的牙齿做**颜色反差**，
> 这样它看着挺凶，但又会有一种西装绅士的憨感 …
> **IP 不能靠换服饰、靠表情来制造特征，真正的记忆点要长在原型结构里。**」

**改稿动作**：
1. 先做**剪影测试** —— 只看黑块，能不能认出来、能不能看出性格
2. 收掉"碎"的外沿：毛刺、多段突起、过多小结构
3. 把识别点**合进主轮廓**，而不是挂在轮廓外面当装饰
4. 圆/方/三角等形态语言要和性格一致（圆=亲和、方=可靠、锐角=攻击性）
5. **弱化对"眼神"的依赖** —— 如果酷/凶只能靠瞪眼表达，说明轮廓没做到位

## 三、变量二 · 比例（气质 / 性格）

**判断标准**：换一个画风、换个人重新画，比例不变的话，还是它吗？

**他的核心论述**：
- 同一只狮子，只改比例，气质全变了
- IP 没性格，多半是比例太过于普通
- IP 形象做不出差异？用比例做出性格
- 把 IP 形象设计做出性格，试试先调比例
- IP 形象没性格，试试先调整身体四肢比例
- IP 设计没特点？试试修改一下结构比例
- IP 形象没性格，很可能卡在比例轮廓这一步

**关键洞察**：**比例就是性格的编码。**
不是靠表情、不是靠服装，而是头身比、四肢长短粗细、体块关系在说话。

**口播原文还原（1.6万赞《同一只狮子 只改比例 气质全变了》）** —— 这是他的标准演示模板：

> 「你画的 IP 是不是总觉得没劲？看这只狮子，像，但是没特点，**为什么？比例太安全了**。
> 如果**体量放大，重心下沉** → 更憨、更稳；
> **线条拉直，身体收紧** → 开始凶，不太好惹；
> **整体压缩，体块变圆** → 更软、更可爱；
> **身体拉长，四肢变细** → 开始怪，有点戏剧感。
> **比例不拉开，永远安全；安全就等于普通。**」

**口播原文还原（1.6万赞《为什么有些角色一出场就有气质》· 老虎版）**：

> 「这是一只普通比例的老虎，能看，但是缺少记忆点。
> **身体拉长、腿部缩短、四肢变细** → 性格变得滑稽、搞怪；
> **体块放大、重心下移、胳膊变粗** → 性格变得憨厚，更有钝感；
> **线条拉直、头和身体缩小、四肢拉大** → 更酷，更有力量感；
> **头放大、身体缩小** → 幼态感马上变强。
> 所以很多角色没气质，**不是细节不够，是比例这一步没把感觉立住**。
> **表情决定情绪，轮廓决定气质。**」

**⚠️ 关键增量：比例不只定性格，还直接决定"该做什么产品"（444 集）**

这是他口播里最实用、却最容易被漏掉的一层。**比例 → 气质 → 适配的载体类型**：

| 比例做法 | 出来的气质 | 适合做成什么 |
|---|---|---|
| 身体缩小、四肢拉长 | 更有戏剧感，支点明确 | **动态 / 动画**（适合做动作） |
| 体量放大、重心下沉 | 更憨厚，识别点明显 | **吉祥物** |
| 线条拉直、轮廓变硬 | 气质变高，重心稳定 | **手办** |
| 轮廓变圆、比例压缩 | 更软萌，单点记忆强 | **表情包** |

> 原话：「**比例决定气质，IP 类型决定设计路径。**」（444 集）

→ 实操含义：**别先画完再想做什么产品。** 先定产品（表情包？手办？毛绒？），
再按上表反推比例。这与 04 的「载体决定原型」是同一条逻辑，只是粒度更细。

**比例 → 性格 速查（从他 20+ 条口播里归并）**：

| 比例动作 | 性格结果 | 出处（口播） |
|---|---|---|
| 体块放大、重心下沉、四肢变粗 | 憨厚、敦实、有钝感、可靠 | 1.6万赞、433、500、679 |
| 头放大、身体缩小、四肢收小 | 幼态、萌、可爱、想被照顾 | 430、433、679、4177 |
| 身体拉长、四肢细长 | 灵、敏感、古灵精怪 / 荒诞、滑稽 | 430、500、1.6万赞 |
| 线条拉直、轮廓变硬、四肢拉大 | 冷、酷、力量感、攻击感、不好惹 | 433、430、1.6万赞 |
| 头身连体、揉成一个团 | 软、想捏一下、软萌 | 320、413、506 |
| 脖子拉长 + 重心压低 | 笨重 + 僵直的反差 → 荒诞 | 390 |
| 身体纵向拉长、整体压圆 | 搞怪、有细分感 / 乖巧、体块集中 | 413、500 |

**改稿动作**：
1. 列出现有比例（头身比、四肢长度、体块宽度关系）
2. 写出目标性格（调皮/稳重/呆萌/凶/贱…）
3. 把性格翻译成比例偏差：
   - 头大身小 → 幼态、可爱、无害
   - 腿短身长 → 笨拙、憨
   - 四肢细长 → 灵动、敏捷
   - 体块方厚 → 可靠、力量
   - 极端比例（过大/过小/过细） → 性格外显
4. **只改比例，先不动细节**，看性格是否已经出来了
5. **再反查**:现在这个比例，最该做成什么产品？（见上表）

> "比例太过于普通"是 IP 没性格的头号原因 —— 普通比例＝平均脸＝没有信息量。
> 更狠的一句：**「比例不拉开，永远安全；安全就等于普通。」**

## 四、变量三 · 五官位置大小（情绪 / 表情）

**判断标准**：同一张脸，只移动/缩放五官，情绪是否显著变化？

**他的核心论述**：
- 同一张脸，只改五官位置大小，情绪就会完全不同
- 很多 IP 表情没特点，**不是不会画，是五官的位置和大小没摆对**
- 同样的轮廓，五官一动，性格、情绪、记忆点都会变
- 一个角色有没有性格，不是只看脸
- IP 形象表情不生动，问题可能在五官位置
- IP 设计表情情绪不足？试试调整五官位置

**改稿动作**：
1. **先别重画** —— "IP表情没特点，先别急着重画"
2. 在现有轮廓里，只动五官（眼距、眼高、眼大小、嘴位、嘴宽）
3. 每动一组，对照目标情绪检查（见下表）
4. 这一步的杠杆率极高：**不动轮廓、不动比例，只挪五官就能换情绪**

**口播原文还原 · 五官 → 情绪 映射表**

**归纳出的三条规律**（整理者归纳）：
1. **重心上移 + 五官放大** → 亲和、幼态、呆萌（"无害向"）
2. **重心下移 + 眉眼压低 + 五官收紧** → 攻击、冷、凶（"威胁向"）
3. **嘴部放大** → 情绪外放开关（搞怪、兴奋、见笑）；**嘴部收小 + 眼放大** → 内敛讨喜

**⚠️ 一条硬约束（534 / 626 / 1391 反复强调）**：
> 「表情这件事，真不是靠堆细节，而是**先用五官之间的关系，把情绪拉开**。」
> 「很多时候，不是画的不够多，是**五官关系还没被拉开**。」

→ 情绪是靠**五官之间的相对关系**（眼距 vs 鼻位 vs 嘴位 vs 重心）制造的，
加线条、加纹理、加高光**不解决**情绪问题。

## 五、结构 vs 装饰（最容易搞错的一件事）

**第17集原文（阿乐改稿）：**
> IP 真正的记忆特征，要长在**结构和比例**里。
> 服饰和配饰可以强化主题，但**不能代替角色本身的特点**。
> 因为任何 IP 都可以换服装、加配饰、做主题延展。
> **拿掉这些外在元素，依然能被认出来的，才是这个 IP 真正的核心特征。**

**第19集标题**：IP 的性格特征，**不能只靠换表情**，要长在**原型结构**里。

**推论 —— 一个自查动作**：
> 把你这个 IP 的服装、配饰、道具、妆容全部拿掉，只留素体。
> 还能认出它吗？还能看出性格吗？
> **不能 → 你的"特点"是装饰，不是结构。装饰可以换，结构必须重做。**

**口播原文还原（390 集《一个角色有没有性格，不是只看脸》）** —— 这一段把"结构 vs 装饰"讲得最狠：

> 「很多 AI 生的形象，看起来有情绪，其实**只是脸上多了个表情**。比如这只企鹅，半眯着眼，
> 圆圆的，看起来有一点呆，但问题是 —— **他的性格主要停留在了表情上，表情一坏，角色就没了**。
> 那你看：先把**身体重心压低**，让他看起来更笨重；再把**脖子稍微拉长**，
> 让身体多一点僵直的反差；**眼睛放大，保持半睁的状态**，让眼神有一点失焦；
> **嘴巴也不放正，稍微歪一点**。
> 他就从一只普通的圆滚滚的企鹅，变成了一只**刚睡醒、看什么都不太顺眼**的企鹅。
> 他的呆萌和荒诞，**不是靠一个表情拼出来的，而是从结构、比例、细节、姿态一起长出来的**。
> 所以 **IP 设计不是给角色加情绪，而是把情绪变成结构。**」

**核心判据一句话**：
> **「表情一坏，角色就没了」→ 说明性格长在表情上，不在结构上。**
> 把表情换成中性脸，你还能看出它是谁、什么性格吗？

对照检查（同一集给出的可操作差异）：

| 只改表情（❌） | 把情绪做进结构（✅） |
|---|---|
| 加一个半眯眼 | 身体重心压低 → 笨重 |
| 嘴角画上扬/下压 | 脖子拉长 → 僵直的反差 |
| 加眼白高光 | 眼神失焦（眼放大 + 半睁） |
| —— | 嘴巴不放正、稍微歪 → 荒诞感 |

**776 集同一论点的另一表述**：
> 「这是 AI 生成的猫，看得挺凶，但还是太常见了，因为它的头型、眼睛和表情都是比较标准的生气猫。
> 如果把**头部更图形化、把脸两侧向外拉开**，在**轮廓上就增加识别度**；
> 再把眼睛放大、图形化，重心下移，黑眼仁做成竖像的，普通的嘴改成努嘴，
> **角色就不只是凶，而是多了一点不服气、又有点天然萌的反差感**；
> 最后把身体缩小，让视觉重心主要集中在脸上。
> **IP 设计要让特征和性格长在结构里，这样无论怎么延伸，识别点都稳定。**」

## 六、"偏差"：AI 生成的 IP 为什么普通

**第16集标题**：AI生成的角色为什么普通？因为少了"**偏差**"。

**口播原文还原（1023 集《AI生成的角色为什么普通？因为少了"偏差"》）** —— 这是他的原始定义：

> 「帮 AI 改稿，这是 AI 生成的一只呆呆狗，看每个点都差一点，有点傻，但还不够有性格。
> 如果把身体用基础几何轮廓建立角色识别点，头身连体、耳朵向后，角色的轮廓就会更抽象、更荒诞；
> 如果再把眼睛放大、视线向两侧偏，脖子伸长、向后甩，手插进裤子里，
> **这个"呆"就不止停在表情上，变成了一种状态** —— 身体已经向前走，但脑子还没跟上，这种感觉。
> **太安全的角色往往没有记忆点。商业设计要做的，就是把"有效偏差"拉出来，因为有偏差才会形成记忆点。**」

**关键词：有效偏差（不只是偏差）**。
- 偏差 ≠ 随便画得怪。**怪而无意 = 噪音；怪而有指向 = 记忆点。**
- "有效"的判据：这个偏差**是否指向一个可被描述的性格状态**（如"身体走了脑子没跟上"）。

**他给出的 AI 改稿三步（824 集原话结构）**：
> 「如果身体放大，手脚变粗，腿缩短 → 显得更可靠，有憨憨的力量感；
> 再**把脸鼓一点、鼻子放大、眼距拉近** → 呆呆的、钝钝的感觉就被放大；
> 再往下，**给他换上不同的衣服和身份** → 改完之后除了原型有特点，还会很容易延伸出一整套 IP 识别。
> 所以很多 AI 生成的 IP，问题不是不好看，而是**太标准、太平均，导致记不住**。」

→ 注意顺序：**先结构（比例+轮廓）→ 再五官（情绪）→ 最后才是服饰身份（延展）**。
这正好是 03 三变量的严格顺序，也是他在 AI 改稿里反复演示的固定动作序列。

**这条解释了为什么他的改稿视频里 AI 相关占了近半**：AI 解决了"出图效率"，但**解决不了"偏差"**——偏差必须由人按三变量手动注入。

## 七、"兴趣成因"：别抄爆款表面

**阿乐体系第5集**：别抄爆款表面，去拆**兴趣成因**。

**口播原文还原（48 集，以 Labubu 正面拆解）** —— 这是全套里最锋利的一段：

> 「**别抄爆款 IP 的表面，要拆解它为什么吸引人。**
> 很多商家看到一个 IP 火了，第一反应就是仿一个差不多的，把它表面的元素改改形状和细节。
> 比方说看到拉布布卖得挺好，就去仿它的大眼睛、尖牙齿、怪表情和毛绒感。
> 但这种做法是**山寨品的设计路径**。
> 看到爆款，真正该拆解的不是它长什么样，而是**它为什么成立，为什么让人停下来**。
> 它的**长耳朵是轮廓的符号**；**尖牙和咧的大嘴是符号，但也是视觉的重心**；
> **皱眉、圆眼睛、咧嘴是情绪的组合 —— 可爱里带点坏，奇怪又不吓人**。
> 这种**反差关系**才是它真正吸引人的原因，**也是兴趣基因**。
> **设计不是复制眼睛所看到的结果，而是重构大脑理解的关系。**」

**他随即给出了自己的迁移示范（同一集）**：

> 「比如我之前改东北虎 IP 的示范，用的也是拉布布这种**情绪反差符号的重新构成**，
> 再把这些关系放回东北虎自己的原形里：**虎头是外轮廓、是符号；虎牙和嘴部是视觉中心；
> 花纹与表情制造情绪的反差。**
> **抄表面是复制结果，猜兴趣基因是理解成因。**
> 再根据新的对象和目的来完成重构，才有机会长出自己的东西。」

**→ 拆解模板（从他的示范里抽出来，可直接套用）**

面对任何爆款 IP，按这张表拆，而不是拍张照临摹：

| 拆解项 | 问什么 | Labubu 的答案 |
|---|---|---|
| **轮廓符号** | 哪个部位是"剪影一眼认出"的？ | 长耳朵 |
| **视觉重心** | 视线最终落在哪？（符号同时是重心时才有效） | 尖牙 + 咧开的大嘴 |
| **情绪组合** | 哪几个元素合起来制造了什么情绪？ | 皱眉 + 圆眼 + 咧嘴 = 可爱里带坏，奇怪但不吓人 |
| **反差关系** | 内部有什么矛盾？（这才是真正的兴趣基因） | 可爱 ↔ 坏；奇怪 ↔ 不吓人 |
| **迁移落点** | 把这套"关系"放回我自己的原型上，长什么样？ | 虎头=轮廓符号，虎牙嘴部=视觉重心，花纹表情=情绪反差 |

> 抄形式不抄作用 → 必死。（呼应 01 的核心：形式制造作用）
> **抄表面 = 复制结果；拆成因 = 理解关系。**

## 八、跨载体验证：368 集完整商业设计链条（口播原文）

368 集《一点小改动，让角色更生动》是他**唯一一条把三变量＋载体约束串完整讲**的口播，
可作为整个 03 的**综合范例**（东北虎 / 足球队吉祥物）：

> 「这个是东北虎的吉祥物，设计得很稳，**稳到所有人都能接受，但也会失去特点**。
> 如果换成商业设计思维，我会先考虑**识别性**：
> **先把头部轮廓做得有符号感，第一步就与普通的老虎分开**（← 变量① 轮廓）；
> **再加一个大大的嘴，体现东北热情、大大咧咧的感觉和积极向上的体育精神**（← 元素关联）；
> **眼睛不能太小，太小会显得局气；但也不能太大**（← 变量③ 五官有上下限）；
> **角色的情绪落点还是嘴**；
> **身体不能做得太短，因为角色后面要做运动员身，需要足够的身体结构**（← 载体约束）；
> **脚大一点是为了突出球鞋，关联足球赛的识别**（← 载体要求反推形式）；
> 这样改会少一点稳重感，但**角色特征会更强**。
> 总结：**轮廓决定识别，元素决定关联，结构决定延展。**」

**这段的四个可复用要点**：
1. **"稳"是缺点** —— 稳到所有人都能接受 = 谁都不会记住。
2. **五官有上下限** —— 眼睛太小"局气"，太大失控。不是越大越好，是**落在能表达目标情绪的区间内**。
3. **载体提前介入** —— "因为后面要做运动员身"、"脚大是为了突出球鞋"。
   **不是先画完再适配产品，而是产品需求在画之前就约束了比例与结构。**
4. **三句话收尾** —— 轮廓→识别、元素→关联、结构→延展，一条动作对应一个目的，不重叠。

## 九、改稿标准作业顺序（SOP）

```
1. 先判断第一用途（走 02，类型错了下面全白做）
2. 先定落地载体（毛绒？手办？表情包？动态？门头？）
   └ 载体约束必须提前 —— 工艺与使用场景会反推比例和结构（368、109、119 集口播反复强调）
3. 剪影测试 → 轮廓能不能认、能不能出气质
   └ 不行 → 改轮廓（收边缘、让识别点成为视觉重心、定形态语言、弱化对眼神的依赖）
4. 比例对照 → 列现有比例 vs 目标性格
   └ 不匹配 → 只改比例，先不碰细节
   └ 同时反查：这个比例最该做什么产品（444 集 比例→载体 对照表）
5. 五官微调 → 只挪五官位置大小，把"五官关系"拉开
   └ 换情绪，不重画
6. 中性脸测试 → 把表情换成中性脸，还认得出、还看得出性格吗
   └ 认不出 → 性格长在表情上了，回到 3/4 重做（390 集）
7. 素体测试 → 拿掉服装配饰，还能认出来吗
   └ 不能 → 特点长在装饰上，回到 3/4 重做
8. 载体验证 → 进包装/门头/图标/表情包/毛绒，还成立吗
9. 偏差自检 → 结构里有几个"有效偏差"？每个偏差指向什么性格状态？
   └ 说不出指向 → 那是噪音，不是记忆点（1023 集）
```

**绝对禁止的动作**：
- ❌ 一上来就加细节（"别加细节，先改轮廓"）
- ❌ 靠换表情解决性格问题（"性格特征不能只靠换表情"；"表情一坏，角色就没了"）
- ❌ 靠加服装配饰解决记忆点问题（"记忆点不是装饰出来的"）
- ❌ 表情没特点就整张重画（"先别急着重画"）
- ❌ 画完才想做成什么产品（368 集：载体在画之前就约束结构）
- ❌ 直接抄爆款的视觉结果（"抄表面是复制结果，猜兴趣基因是理解成因"）
- ❌ 为了"稳"而收敛比例（"比例不拉开，永远安全；安全就等于普通"）
