## 一、为什么先判断"第一用途"

很多人以为，做 IP 是先做一个形象。
可爱一点？好看一点？有特点一些？能不能做周边？能不能像某个爆款一样火？

这些问题当然重要。**但它们不是第一问题。**

因为同样都叫 IP，**雪王、拉布布、线条小狗、哪吒，解决的并不是同一件事**。
它们都可以被识别、被传播、被喜欢、被消费，也都可以做周边，**但它们成立的原因不一样**：

- 有的 IP 是为了代表品牌
- 有的 IP 是为了刺激购买
- 有的 IP 是为了让用户表达情绪、快速转发
- 有的 IP 是为了持续讲故事，支撑内容和世界观

所以做 IP 之前，**最先要判断的不是它长什么样，而是它的第一用途是什么**。

这里说的「第一用途」，就是从商业角度看，**这个 IP 在当下阶段最先要解决什么问题**。

第一用途不同，设计侧重点就不同。如果这一步没有判断清楚，后面就很容易乱：

- 明明需要被记住，却一直在追短期流行
- 明明需要卖货，却做成了一个很稳的品牌吉祥物
- 明明需要文化转译，却只往角色身上堆元素
- 明明需要用户传播，却把形象做得太完整、太沉重

## 二、五型速查表

| 类型 | 第一用途 | 首要任务 | 设计侧重 | 最容易犯的错 | 代表案例 |
|---|---|---|---|---|---|
| **① 品牌型** | 解决**品牌记忆** | 让人快速记住「它代表谁」 | 稳定轮廓/比例/色彩关系/核心符号；可标准化、可缩小成图标 | 一开始做得太复杂；追短期流行 | 天猫、蜜雪冰城雪王 |
| **② 产品型** | 解决**即时购买欲望** | 制造拥有欲 | 即时吸引力：情绪抓人、造型吸睛、材质质感、系列收藏欲 | 品牌 IP 还没立住就做周边 → 变成一批临时产品 | Labubu、Crybaby、Farmer Bob |
| **③ 社交型** | 解决**用户表达** | 让用户拿它表达自己 | 简单直接、低理解成本、有情绪代入、方便转发 | 追求设计壁垒／复杂世界观 → 传不动 | 线条小狗、Chiikawa |
| **④ 文化型** | 解决**文化转译** | 把文化资源变成当代人愿意看/用/传的东西 | 提炼（不是堆元素）+ 载体适配 | 什么都往里堆 → 有文化但识别不清 | 城市/景区/博物馆/非遗 IP |
| **⑤ 内容型** | 解决**承载故事和关系** | 能不能持续发生内容 | 服务内容内核：性格、关系、冲突、故事空间 | 只做一张设定图就当 IP | 电影哪吒、小王子 |

## 三、五型详述

### ① 品牌型 IP：解决品牌记忆

这里说的品牌型 IP，更适合指那些想要**长期传播、标准化、规模化应用**的品牌形象。

**所以不能一开始就做得太复杂。**
品牌型 IP 的第一任务，不是让人研究它有多少细节，而是形象风格要持久，要让人**快速记住：它代表谁**。

它要标准化地出现在线下门头、包装、海报、物料、活动现场，也要出现在小程序、线上店铺、社交内容和各种传播媒介里。

甚至，品牌 IP 还要能被**进一步提炼成图标**（如天猫）。
**缩小以后还能识别。换一个物料还能成立。放到不同场景里还能稳定出现。**

这意味着，品牌型 IP 要把**识别点做进稳定结构里**：

- 稳定的轮廓
- 稳定的比例
- 稳定的颜色关系
- 稳定的核心符号
- 以及不同场景下稳定的标准化应用

如果一个 IP 不好放进物料，也不好进入传播媒介，就很难反复触达用户。

> **造型解决的是识别，人格行为解决的是持续传播。**
> 不能反复触达用户，就很难形成品牌记忆。不能形成品牌记忆，也就很难成为品牌资产。

成熟品牌型 IP 的画风各不相同，但它们共同解决的是同一个问题：**品牌记忆**。

**识别，才容易被记住。稳定，才容易被应用。简约，才容易被延伸。**

用户看到这个形象，不是先研究它的故事，也不是先想买一个玩具，而是**先想到它背后的品牌**。

---

### ② 产品型 IP：解决即时购买欲望

产品型 IP 的第一用途，更直接地指向**销售转化**。

比如拉布布这一类潮玩角色。它最核心的作用，不是让用户先想到某个品牌，而是**让用户产生拥有欲**：想抱着、想收集、想挂在包上、想摆在桌上、想让它陪伴自己。

所以产品型 IP 的重点，是**即时吸引力**：

- 情绪要抓人
- 造型要有吸引力
- 材质要有质感
- 系列要有收藏欲
- 要有被拿起来、带走、拥有的理由

**产品型 IP 和品牌型 IP 不一样**：品牌型 IP 更看重长期识别和品牌绑定；产品型 IP 更看重即时欲望和消费转化。

**这里最容易混淆。**
很多品牌看到拉布布这类产品型 IP 火了，也会想：那我是不是也可以做一套自己的周边？

当然可以。但**要先判断清楚：用户买这个周边，是因为喜欢这个角色本身，还是因为已经对你的品牌有认知和情感？**

如果品牌本身还没有一个清晰的品牌 IP，直接做周边，就很容易变成**一批临时产品**。东西做出来了，但品牌资产没有沉淀下来。

所以这里不是品牌型 IP 比产品型 IP 更好，而是**两者的起点不同**：

- 核心目标是**建立品牌资产** → 第一步更应该做品牌型 IP
- 核心目标是**不断开发形象、持续迭代产品、形成可销售可收藏可上新的角色产品** → 属于产品型 IP

品牌型 IP 和产品型 IP 是**战略上两条不同的线**。两者都可以做周边，**但设计路径完全不同**。

---

### ③ 社交型 IP：解决用户表达

社交型 IP 的第一用途，是**让用户拿它表达自己**。最常见的就是表情包、头像、评论区配图这一类。

- 品牌型 IP 要先建立长期识别
- 产品型 IP 要先制造购买欲望
- **而社交型 IP，最先要解决的是情绪表达**

比如线条小狗。它不靠复杂世界观成立，也不靠精致造型成立，甚至在前期不一定追求很强的设计壁垒。它真正被传播，是因为它能用**最简单的方式，替用户表达一种日常生活状态**：委屈、发疯、摆烂、撒娇、无语、累了——但还要活着。

用户用它做头像、表情包、评论区配图，或者转发它，**本质上是在使用一个情绪替身**。

所以社交型 IP 的重点，不是先建立独特角色设定，也不是先服务品牌识别，而是**让用户理解成本极低、马上能拿去表达**：

- 简单直接
- 低门槛
- 有情绪代入
- 方便被使用和转发

**但它的问题也很明显**：设计壁垒低，容易被模仿，生命周期不稳定，很依赖情绪热点和平台传播。

所以社交型 IP 很容易短期爆发，但不一定天然就是长期资产。它前期靠的是共感；后期如果想走得更远，**就要完成一次转向**：

- 从情绪表达 → 转向稳定识别
- 从表情传播 → 转向角色资产
- 从社交热度 → 转向产品、授权和品牌闭环

Chiikawa 是一个更复合的例子：它不只是社交型 IP，也有内容、产品和角色关系。但它能被大量传播，很重要的一点是它有**很强的社交表达属性** —— 很多人喜欢它，不只是喜欢角色本身，而是**觉得它像自己的某种生活状态**。

> 社交型 IP：它不是先问「这个角色是谁」，而是先问「**用户可以用它表达什么**」。

---

### ④ 文化型 IP：解决文化转译

- 品牌型 IP：通常是**品牌需求**在前
- 产品型 IP：通常是**消费欲望**在前
- 社交型 IP：通常是**情绪表达**在前
- **文化型 IP：往往是文化母体在前**

它可能来自一座城市、一个景区、一段历史、一种地域民俗、一批文物，或者一个流传已久的故事。

所以文化型 IP 的第一用途，是**把文化资源转化成当代人愿意看、愿意用、愿意传播的东西**。

它不是先靠一个角色成立，而是**先借了文化的势**——文化本身有出处、有故事、有记忆，也可能自带文旅热度和用户靠近它的理由。

设计要做的，不是把这些文化元素全部堆到角色身上，而是**判断**：

- 这个文化里，什么最值得被留下？
- 什么最容易被识别？
- 什么能被当代人理解？
- 什么能转化成产品、空间、活动和传播内容？

它可以继续长成品牌型 IP，也可以开发成产品型 IP，还可以被做成社交传播内容，甚至进一步发展成内容型 IP。**文化型 IP 的起点，始终是文化。**

**这也是文化型 IP 最容易做错的地方。** 很多项目一做文化 IP，就开始堆元素：建筑、纹样、服饰、图腾、历史人物、地方特产，什么都想放进去。最后看起来很有文化，**但识别不清，放到同类产品里也没有竞争力**。

> 如果一个文化型 IP，**必须靠长篇讲解，用户才知道为什么要买**，说明它的**视觉转译还不够直接**。

文化型 IP 是把复杂的文化信息，重新组织成当代人愿意接受、愿意使用、愿意传播的东西。
所以文化型 IP 的难点，**不是装饰能力，而是提炼是否准确、转化到产品载体/空间/传播载体里是否适配**。

---

### ⑤ 内容型 IP：承载故事和关系

内容型 IP 的第一用途，是**承载故事和持续内容**。

内容型 IP 不是靠一张设定图成立，而是靠**故事、人物关系、世界观、情感冲突和连贯表达**成立。

比如电影《哪吒》里的哪吒。他不只是一个传统神话人物，而是在电影里被重新塑造成了一个有叛逆感、有命运感、有情绪爆发点的角色。
**如果脱离电影内容，只看这个形象设计本身，它未必能有很强的竞争力。** 他和父母的关系、和命运的对抗、和自我身份的冲突，才是这个角色真正被记住的原因。

再比如绘本中的小王子，也不是靠一个金发小男孩的形象成立的。真正让它被记住的，是故事里的孤独感、纯真感、关系感和精神气质。

所以内容型 IP 的重点，**不是角色好不好看，而是它能不能持续发生内容**：

- 有没有鲜明性格？
- 有没有独特能力或行为方式？
- 有没有情绪冲突？
- 有没有故事空间？

内容型 IP 的形象设计，要**服务内容内核**：要先判断它要承载什么样的内容、关系和情感，再塑造最贴合的形象。
**如果角色的性格、关系和特征没有被情节撑开，它就很难成为卖座的内容型 IP。**

---

## 四、第一用途 ≠ 唯一用途

IP 类型不是永远锁死的。一个成熟的 IP，后面可能会跨到很多用途里：

- 内容型 IP 可以变成品牌资产
- 品牌型 IP 可以开发产品周边
- 产品型 IP 可以反过来长出内容
- 社交型 IP 也可能形成商业授权和产品转化
- 文化型 IP 也可以生长出角色、产品和内容

所以**第一用途不等于唯一用途**，它是为了帮助我们判断：**这个 IP 在当前阶段，最先要解决什么问题。**

比如皮卡丘、米奇。它们并不是一开始作为普通品牌吉祥物出现的，它们有内容、有故事、有角色关系，也有长期的用户情感积累。但后来它们同样可以成为很强的品牌型 IP —— 因为用户看到它们，就能立刻识别出背后的故事、品牌和文化资产。

**这里提一个关键原因：它们的基础形象识别足够强。**

轮廓简单 / 比例稳定 / 结构清楚 / 符号明确 / 局部特征容易被记住。
**哪怕只看到米奇的圆耳朵、皮卡丘的闪电尾巴，用户也能快速识别。**

所以，一个 IP 后期能不能跨类型延展，还要看它**底层识别结构够不够成立**。
如果基础形象本身有记忆点，后面无论做品牌、产品、社交还是内容，都会很顺畅。

---

## 五、结论

同样都叫 IP，但跑通的原因不一样。

- **不能用做短期流行的表情包逻辑，去做长期的品牌符号。**
- **不能用做剧情角色的方式，去做文创产品。**

IP 分类不是为了给形象贴标签，而是为了**判断设计该往哪里用力**。

> 做 IP 之前，先判断第一用途。
> 第一用途清楚，设计路径才清楚。
> 因为只有先知道 IP 要解决什么问题，才知道它的形式应该服务什么作用。
>
> **先判断，再设计。** —— 徐阿乐®设计系统
