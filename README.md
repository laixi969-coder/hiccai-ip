# hiccai-ip

IP 形象设计与诊断 skill。核心一句话：**先判断，再设计** —— 先判断这个 IP 要产生什么作用，再反推它该用什么形式。

## 它解决什么问题

大多数 IP 做不出来，不是画功问题，是**动手前没做判断**：

- 不知道这个 IP 当前最先要解决什么（品牌记忆？卖货？用户表达？文化转译？承载故事？）
- 一上来就加细节，而真正该动的**轮廓、比例、五官**没动
- 差异做在服装配饰上，拿掉就回到同一个角色
- 只做统一性，结果 5 个角色像一个
- 原型直接复刻成周边，做出来只能摆着，用不上
- AI 出图看着可爱但记不住 —— 因为它给的是平均值

这个 skill 把上述每一步都拆成可判断、可执行、可验收的动作。

## 三层结构

| 层 | 内容 | 回答 |
|---|---|---|
| 一 · 设计观 | 用形式制造作用 | 设计到底在干什么 |
| 二 · 第一用途 | 品牌型 / 产品型 / 社交型 / 文化型 / 内容型 | 这个 IP 最先解决什么问题 |
| 三 · 三变量 | 轮廓 → 比例 → 五官（严格顺序） | 具体怎么改 |

四条设计路径：品牌型（关联性·符号性·延伸性）、产品型（兴趣基因·产品适配·差异化）、
系列 IP（统一性·差异性·关系感）、文创（文化母体·转化载体·购买理由）。

## 素材来源与可靠度

方法论整理自 **抖音号「徐阿乐 IP判断」**（抖音号 `xhomsv`）的公开输出：
58 条作品、4 个合集 55 集，其中 **54 条视频的口播已通过本地语音转写逐字还原**。

| 层级 | 内容 | 可靠度 |
|---|---|---|
| L1 口播原文 | 54 条视频语音逐字转写 | 高（语义准确，个别同音字） |
| L2 长文原文 | 两篇本人署名长文 | 高 |
| L3 标题与文案 | 作品与合集标题、话题标签 | 中 |
| L4 整理者归纳 | 优先级表、速查表、体检表、六步流程 | 方法论延伸，非原话 |

**已知同音字误差**：他在视频里自称时常被转写成「薛阿乐」，实际是「徐阿乐」。
其余易错项（鬼将/龟匠、虢国夫人/国国夫人、Labubu/拉布布、轮廓/容阔、憨厚/寒厚）
见 `references/10-spoken-corpus.md` 开头。
